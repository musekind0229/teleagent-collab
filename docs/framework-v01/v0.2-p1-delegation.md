# Agent Exec Framework v0.2 — P1 minimal delegation + durable caller

Design: `/workspace/agent-exec-framework-v0.2.md` §5 / §8 / §11 P1.  
Baseline map: [`v0.2-p0-map.md`](v0.2-p0-map.md).

Reuse existing Goal / plan / knife-14 five ops. Kernel stores declared
delegation fields and accepts or refuses. No Bot product, no Hermes, no
deploy, no glue rewrite, no P0 module rewrite, no P2.

## What P1 adds

| Semantic | Where | Rule |
| --- | --- | --- |
| Autonomy scope | `submit_goal(autonomy=…)` | `explicit_plan` (no local plan/rework/reassign) vs `bounded_autonomy` (contract-internal plan revision still allowed, P0 ceiling still applies). Stored on the Goal snapshot and on the ownership store; `validate_plan_revision` / `submit_plan_revision` respect it. |
| Submitter identity | `submit_goal(submitter_id=…, external_goal_ref=…)` | Recorded for audit on submit / get / report. Same-key content conflict stays P0 (`submit_content_conflict`). |
| Return-to-upper | `escalate_to_upper` | Over-budget, out-of-scope, insufficient-auth become **pending decision kinds** (`escalate_over_budget`, `escalate_out_of_scope`, `escalate_insufficient_auth`). `silent_retry=false`. Upper (`submitter_id`) or the live coordinator may `resolve_decision` with `actor_id`. |
| Ownership | submit claim + get projection | If `coordinator_id` is passed on submit, existing `GoalOwnershipStore.claim` runs. `get_goal` / `get_report` show `ownership.coordinator_id` + `version`. `handoff` wraps existing `handoff` (version bump). |

Undeclared autonomy keeps P0 plan-revision behavior (b12 unchanged). Submit
without a coordinator still has no ownership projection (b14 unchanged).

## Code

- `src/framework/delegation.py` — autonomy normalize + plan-vs-scope check + escalate kinds
- `src/framework/durable_api.py` — submit/get/report fields; `escalate_to_upper`; `list_events`; `handoff_coordinator`
- `src/framework/goal_ownership.py` — store autonomy; refuse local revision under `explicit_plan`
- `src/framework/charter_map.py` — optional charter passthrough (`autonomy` / `submitter_id` / `external_goal_ref`) onto `role_hints` + mapped extras
- Caller: `bin/durable-cli.py` (extended) and `bin/delegate-demo.py`
- Tests: `src/test_framework_v02_p1.py`

`bin/run-job.py` default remains TeleAgent. `--dry-run` still does not touch a backend.

## Simple caller

File-backed persist dir (creates `.collab-durable/` and, when a coordinator is
claimed, `.collab-goal-ownership/`). No HTTP.

### Demo (one shot)

```bash
PYTHONPATH=src python3 bin/delegate-demo.py --persist /tmp/p1-demo
```

### durable-cli sequence

```bash
PERSIST=/tmp/p1-cli
PYTHONPATH=src

python3 bin/durable-cli.py --persist "$PERSIST" submit \
  --submit-key p1-login \
  --title "fix login double-submit" \
  --outcome "idempotent login; no deploy" \
  --submitter upper-bot-1 \
  --external-goal-ref parent:week-internal-beta \
  --autonomy bounded_autonomy \
  --coordinator coord-local-1 \
  --budget-json '{"wall_sec":120,"max_reworks":2}' \
  --boundaries-json '{"must":["stay in workspace"],"must_not":["deploy"]}'

# copy goal_id from submit JSON
GID=goal_…

python3 bin/durable-cli.py --persist "$PERSIST" get "$GID"
python3 bin/durable-cli.py --persist "$PERSIST" events "$GID"

python3 bin/durable-cli.py --persist "$PERSIST" escalate "$GID" \
  --kind over_budget \
  --reason "wall_sec reserve would exceed Goal budget"

python3 bin/durable-cli.py --persist "$PERSIST" pending "$GID"

# copy decision_id from escalate JSON
DID=dec_…

python3 bin/durable-cli.py --persist "$PERSIST" resolve "$GID" \
  --decision-id "$DID" \
  --verdict ack_raise_budget \
  --reason "upper will revise contract; do not retry locally" \
  --actor-id upper-bot-1

python3 bin/durable-cli.py --persist "$PERSIST" report "$GID"
python3 bin/durable-cli.py --persist "$PERSIST" cancel "$GID"
```

`get` shows `autonomy`, `submitter_id`, `external_goal_ref`, and `ownership`
(`coordinator_id` + `version`). `events` tags escalate rows as
`event_class=decision_required` (not a status ping). `cancel` lands
`cancel_requested` (`cancelled=false`).

Optional handoff (existing ownership op, version bump):

```bash
python3 bin/durable-cli.py --persist "$PERSIST" handoff "$GID" \
  --from-coordinator coord-local-1 \
  --to-coordinator coord-local-2 \
  --version 1
```
